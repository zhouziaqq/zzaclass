# 肘子大王の课表 · 静态网页版

把**教务系统导出的课表 PDF** 变成一张好看的课程表网页：默认显示「今天」要上什么课，也可以切换到整周课表；
每节课默认只显示**课程名称 + 地点**，鼠标悬停（或键盘聚焦）就展开**全部信息**（教师、周次、校区、教学班、学时、备注）。

打开时会有一个约 **1 秒的「肘子大王」欢迎动画**（可在主界面关掉，关掉后下次打开不再出现，也能随时再打开）。

- 纯静态，**双击 `index.html` 即可打开**，不需要装环境、不需要联网、不需要本地服务器。
- 解析与渲染全部在浏览器本地完成，导入的 PDF 不会上传到任何地方。
- 作息时间按学校规则计算：每节 45 分钟、课间 10 分钟、第 1 节 08:20、第 3 节 10:20（第 2 节后 20 分钟大课间）、
  第 5 节 14:00（12:00–14:00 午休）、第 11 节 20:20。

### 欢迎界面（肘子大王出场）

打开页面时会显示约 **1 秒**的欢迎动画（🏆👑 皇冠落下、光环扩散、标题流光、进度条走完，然后模糊放大淡出）。
想关掉有两种方式：

- 欢迎界面上的「以后不再显示欢迎动画」——点了以后再也不出现；
- ⚙️ 设置里的「开启欢迎动画」开关——关掉后下次打开直接进主界面；重新打开时还会**立刻补演一次**作为预览。

关了之后欢迎界面**不会闪一下**（页面在样式生效前就先读本地设置决定是否隐藏）。

### 课表格式（可以随时换）

| 位置 | 格式 | 说明 |
| --- | --- | --- |
| 当天视图 | **卡片**（默认） | 按上午 / 下午 / 晚上分组的卡片，悬停展开全部信息 |
| 当天视图 | **紧凑列表** | 一行一节课（时间 / 节次 / 课程 / 地点 / 教师 / 周次），悬停整行展开详情 |
| 当天视图 | **时间轴** | 按真实时间比例排布的彩色条，带整点刻度、大课间 / 午休 / 晚饭标记，今天还会显示红色「现在」指示线 |
| 周课表 | **彩色网格**（默认） | 节次 × 星期的网格，彩色课程块 |
| 周课表 | **经典表格** | 像教务系统打印出来的方格课表，纯文字 + 悬停展开 |

顶部 🎨 按钮可快速轮换当天视图格式；两种格式都能在 ⚙️ 设置 → 显示格式 里精确选择，选择会被记住。

### 电脑端 / 手机端

打开时会自动判断设备（UA 关键字、窗口宽度、是否触屏为主），也可以**手动切换**：

| 入口 | 作用 |
| --- | --- |
| 顶部 **📱 / 🖥️** 按钮（主界面） | 一键在手机版 / 电脑版之间切换，按钮图标显示「切过去是什么版」 |
| ⚙️ 设置 → 界面端 | `自动识别` / `固定手机版` / `固定电脑版`，选择存在本地，下次打开仍生效 |

判定顺序（自动识别时）：UA 命中 Android / iPhone / 鸿蒙 / 微信等 → 手机端；窗口宽度 ≤ 820px → 手机端；
主指针是触屏（iPad 之类，宽度 ≤ 1180px）→ 手机端；否则电脑端。**窗口拖窄也会自动切到手机端布局**。

手机版和电脑版的区别：

| | 电脑版 | 手机版 |
| --- | --- | --- |
| 视图切换 | 顶部「今天 / 周课表」胶囊按钮 | **底部导航**（今天 / 周课表 / 添加课程 / 设置），大按钮、贴底、带安全区适配 |
| 展开课程信息 | 鼠标悬停 / 键盘聚焦 | **点一下卡片**展开（再点收起，同时只展开一个），悬停提示也改成「点一下卡片也能展开」 |
| 周课表 | 节次 × 星期的 12×N 网格 / 经典表格 | **日期条 + 当天列表**：上方可横向滑动的「周X 日期 几节」，点一下就换天，内容沿用当前「当天视图格式」 |
| 布局 | 多列、宽间距 | 统计栏两列、卡片单列、字号与点击区域放大（≥44px）、对话弹窗全宽、底部留出导航空间 |
| 其它 | 右下角小助手贴右下 | 小助手与提示条自动上移到导航栏之上，避免遮挡 |

> 想关掉手机版回到电脑版：点顶部 🖥️（或设置里选「电脑版」）。iOS 上如果把它「添加到主屏幕」，会按独立 App 全屏打开，界面同样是手机版。

「今天」视图按**上午 / 下午 / 晚上**分组，自动插入 `大课间 10:00 – 10:20`、`午休 12:00 – 14:00`、`晚饭 17:30 – 18:30` 提示条；
当天正在上的课会标「正在上课」，下一节标「下一节 08:20 · 大学英语（一）」。
当天没课时会显示 🎉 空状态，并列出「接下来还有」的最近几节课。

> 周课表最左列的「节次」栏会同时写出**该节的起止时间**，例如 `第 1 节 / 08:20–09:05`、`第 11 节 / 20:20–21:05`，
> 不用再去别的页面换算时间。添加课程的「节次」下拉框里也带同样时间。

## 三、导入新的课表 PDF

**方式 A（网页里导入，推荐）**
1. 打开 `index.html` → 右上角「导入 PDF」（或将 PDF 拖进页面）；
2. 解析成功后立即替换成新课表，并保存在浏览器 localStorage 里；
3. 想换回默认课表：⚙️ 设置 → 「恢复内置课表」。

**方式 B（重新生成内置默认数据）**
```powershell
node tools/build-data.mjs "D:\课表.pdf" data\default-schedule.js
```
这样把新课表写进 `data/default-schedule.js`，任何浏览器打开都是新数据。

> 兼容性说明：解析器针对学校教务系统导出的课表 PDF（iText + STSong-Light / UniGB-UCS2-H 编码）。
> 其他来源的 PDF（扫描件、图片版、其他排版）可能解析不出内容，此时页面会给出提示。

## 四、自主添加课程（长期加入 / 部分时间段加入）

点右上角 **「＋ 添加课程」**（设置里也有入口，或「今天没课」的空状态里也放了按钮）即可添加课表以外的安排，
比如社团例会、辅导班、固定自习、讲座等。

表单可以填：

| 字段 | 说明 |
| --- | --- |
| 课程名称 * | 必填，会显示成一张课程卡片 |
| 地点 / 教师 / 校区 / 备注 | 选填，悬停卡片时能看到 |
| 上课星期 | 可多选（周一～周日），默认勾选今天 |
| 开始 / 结束节次 | 下拉里直接写明时间，如 `第 5 节（14:00–14:55）`；跨多节就选起止两节 |
| 加入方式 | **长期加入**（每周都显示）或 **部分时间段加入**（只在指定周次 / 日期显示） |

「部分时间段加入」可以填：
- **教学周次**：如 `3-8,10`（支持 `3-8`、`3-8周`、`3~5,8` 等写法），按「第几教学周」生效；
- **起始 / 结束日期**：按具体日期生效；
- 两者可只填一个，都填则要同时满足才显示。

自建课程会：
- 与 PDF 课表**合并**显示（同一节次会并排出现在同一格），并带橙色 **自建** 徽标、周课表里用虚线框区分；
- 计入「今天共 N 节」和顶部「自建课程」统计；
- 保存在浏览器本地（localStorage），**导入新学期 PDF 也不会被清掉**；
- 在弹窗下方的「已添加的自建课程」列表里可以**编辑**或**删除**；
- 点「导出当前课表 JSON」时会一起导出。

## 八、解析原理

1. 按对象切分 PDF，取出 `FlateDecode` 内容流，用浏览器自带的 `DecompressionStream('deflate')` 解压（Node 18+ 同样可用，所以网页与命令行共用一份解析代码）。
2. 解释内容流里的 `BT / Tm / Td / Tj / re / cm / q / Q`，得到带坐标的文字与表格线；内容流最外层那个 `cm` 只是把纵向页面旋正，用它的逆矩阵把坐标还原成「页面所见坐标」。
3. `UniGB-UCS2-H` 编码的字符串，码元就是 UCS-2 大端值，直接按 UTF-16BE 解码即可得到中文。
4. 用表格线还原三级结构：**最左列 = 星期分组格**（决定课程属于星期几）、**第二列 = 节次格**（决定 1-2 / 3-4 节）、**右侧整行 = 课程明细行**；
   一行可能有多门课（同一节次、不同周次拆开排），所以节次格会跨多行。
5. 明细行按 `周数 / 校区 / 地点 / 教师 / 教学班 / 教学班组成 / 选课备注 / 课程学时组成` 切开成字段；
   页脚「其他课程：…」解析成独立的「其他课程」列表。
6. 打印跨页时（本课表 PDF 的第 2 页就是星期五的续排），没有星期名的分组格会归到上一页最后一天。

## 十、上线部署（变成在线网站）

先说清楚：**这是纯静态站点**，不需要后端 / 数据库 / Node 服务。解析 PDF、渲染课表、自建课程、主题偏好全在访问者的浏览器里完成，
所以任何静态托管（GitHub Pages / Cloudflare Pages / Netlify / Vercel / 对象存储 / 虚拟主机）都能直接跑。

### 1. 本地先跑一遍（更接近线上环境）

```powershell
cd C:\Users\AO\Desktop\course-schedule
npm run dev          # = node tools/serve.mjs . 8080 --no-cache
# 浏览器打开 http://127.0.0.1:8080/
```

> 双击 `index.html` 也能用；用本地 http 服务的好处是与线上一致（`http://` 下的 localStorage、相对路径、404 页都一样）。

### 2. 打包上线文件

```powershell
npm run build                # 生成 dist/，并自动把学号打码（1361****6026）
npm run build -- --keep-id   # 想保留完整学号再加这个参数
npm run build -- --zip       # 顺便打一个 dist.zip，方便直接上传
npm run preview              # 用本地服务预览 dist/（http://127.0.0.1:8080）
```

`dist/` 里就是**需要上传的全部内容**：`index.html`、`css/`、`js/`、`data/`、`robots.txt`、`404.html`、`.nojekyll`，合计约 165 KB。
（`tools/`、`README.md`、部署配置不会被打包进去。）

> 若 `npm` 在 PowerShell 里报「禁止运行脚本」，把它换成 `npm.cmd`，或直接运行 `node tools/prepare-deploy.mjs`（可加 `--keep-id` / `--zip`）。

### 3. 挑一种托管方式

**方案 A：GitHub Pages（免费、最常用）**

```powershell
# 1) 先在 GitHub 网页上新建一个仓库，例如 course-schedule
cd C:\Users\AO\Desktop\course-schedule
git remote add origin https://github.com/你的用户名/course-schedule.git
git push -u origin main
```

2) 仓库 **Settings → Pages → Source 选 `GitHub Actions`**（仓库里已经带了 `.github/workflows/deploy-pages.yml`，推送后会自动「打包 + 自检 + 部署」）。
3) 访问地址：`https://你的用户名.github.io/course-schedule/`（项目站是子路径形式，**已实测可用**）。

> 不想用 Actions 的话：把 `dist/` 里的文件推到 `gh-pages` 分支，Pages 的 Source 选 `gh-pages` 分支即可。

**方案 B：Netlify（拖拽最快，30 秒上线）**

- 打开 <https://app.netlify.com/drop>，把 **dist 文件夹**拖进去 → 立刻得到 `https://xxx.netlify.app/`。
- 或连 Git 仓库自动部署：New site from Git 选仓库即可（`netlify.toml` 已配好构建命令与发布目录）。

**方案 C：Cloudflare Pages（国内访问通常比 GitHub 稳）**

- 控制台 → Workers & Pages → Pages → 连接 Git 仓库 → 框架预设选 `None`，
  构建命令填 `node tools/prepare-deploy.mjs`，输出目录填 `dist`；也可以用「直接上传」把 `dist` 拖进去。

**方案 D：Vercel**

```powershell
npx vercel --prod     # 首次会引导登录；vercel.json 已配好构建与输出目录
```

**方案 E：国内主机 / 对象存储（速度最好）**

- 虚拟主机、宝塔面板、阿里云 OSS、腾讯云 COS、七牛等：把 `dist` 里的**内容**上传到网站根目录，
  开启「静态网站托管」，把首页设为 `index.html`、错误页设为 `404.html` 即可。不需要 Node、不需要构建。

### 4. 自定义域名 / HTTPS

各平台都在「Domain / 自定义域」里填域名并按提示添加 `CNAME` / `A` 记录；Netlify / Cloudflare / Vercel 会自动签发 HTTPS。
GitHub Pages 绑定自定义域名后也会自动签 HTTPS（想固定域名可加一个内容为域名的 `CNAME` 文件）。

### 5. 上线后的行为（重要）

- **数据在访问者自己的浏览器里**：导入的 PDF 课表、自建课程、主题与格式偏好都存在各自的 localStorage，不会上传服务器；
  换设备 / 清缓存会丢，用 ⚙️「导出当前课表 JSON」备份。
- **默认不让搜索引擎收录**：`index.html` 里有 `<meta name="robots" content="noindex, nofollow">`，
  `robots.txt` 里是 `Disallow: /`。想公开被收录就把这两处改掉。
- **学号默认打码**：`npm run build` 会写成 `1361****6026`；要显示完整学号用 `--keep-id`。
- **子路径部署已适配**：所有资源都是相对路径（实测 `http://…/my-schedule/` 下正常）。
  唯一例外是 `404.html` 里「回到我的课表」用的是站点根路径 `/index.html`，若你部署在子路径又在意这个页面，改成相对路径即可。
- **更新流程**：改完文件 → `npm run build` → 推送仓库（或重新拖 `dist`），平台会自动重新部署。

### 6. 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 打开是空白或 404 | 上传时多套了一层目录。服务器根目录下必须**直接**能看到 `index.html` |
| 样式没生效、按钮点不动 | `css/`、`js/`、`data/` 三个目录没传全（`data/default-schedule.js` 是课表数据） |
| 导入 PDF 没反应 | 手机端顶部没有导入按钮，请到 ⚙️ 设置里点「导入新的课表 PDF」；且必须是教务系统导出的课表 PDF |
| 想换课表数据 | `node tools/build-data.mjs "新课表.pdf" data/default-schedule.js`，然后重新构建部署 |
| 页面更新了但看到旧的 | 浏览器缓存，强制刷新（Ctrl+F5）或等 1 分钟 |

## 十一、已知限制

- 只针对教务系统那种排版（表格线 + `UniGB-UCS2-H` 字体）；换排版或扫描件会解析失败。
- 开学日需要人工确认，默认值只是按打印日期推算的估算。
- 页脚「其他课程」里的教师名与课程名连在一起时，按 ASCII/中文边界拆分；纯中文教师名无法自动分离。
- 同一时间段（同一节次）里的多门课按 PDF 里的顺序展示，不再做周次合并计算。
- 自建课程存在浏览器本地：换浏览器 / 清理浏览器数据会丢失；换设备请用「导出当前课表 JSON」备份。
